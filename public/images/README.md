# Site images

`messy-hold-sign-only.jpg` is the optimized navy-and-orange sign-only artwork used on the homepage and as the default social-preview image. Its generated PNG source, `messy-hold-sign-only.png`, is also retained here. The earlier `messy-hold-navy-orange.jpg` image is no longer used by the site.

The images were generated with the available image tool; no Microsoft-specific model provenance is claimed. For article images, use an article-specific folder and follow `docs/publishing-workflow.md`. Everything in this directory is public.
