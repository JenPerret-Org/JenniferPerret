# Site images

`messy-dimensional-frame-transparent.webp` is the navy-and-orange framed-sign artwork used on the homepage. `messy-dimensional-frame.jpg` is the default social-preview image. Update these respective files when replacing the homepage or default sharing artwork. The `messy-hold-sign-only.jpg`, `messy-hold-sign-only.png`, and `messy-hold-navy-orange.jpg` files are retained artwork variants, not the current homepage or default sharing assets.

The sign images were generated with the available image tool; no Microsoft-specific model provenance is claimed. `jennifer-perret-headshot.jpg` is the author-provided photo used on the About page. For article images, use an article-specific folder and follow `docs/publishing-workflow.md`. Everything in this directory is public.
